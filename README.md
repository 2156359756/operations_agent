## 📋 项目概述

本系统严格遵循「品牌事实与内容策略 → 选题 → 脚本 → 发布物料包」的人机协作生产链路，确保每个关键节点都有人工确认步骤。

### 核心功能

1. **选题生成** - 根据平台、栏目、人群生成创意选题建议
2. **大纲生成** - 基于选题生成结构化内容大纲
3. **脚本生成** - 完整脚本初稿输出
4. **合规扫描** - 自动检测禁用词和医学风险词
5. **图片提示词** - 生成多平台适用的AI绘图提示词
6. **物料包导出** - 一键导出完整Markdown发布包

## 🚀 快速开始

### 环境要求

- Python 3.9+
- 支持OpenAI兼容API的大模型（如GPT-4、Claude、本地部署模型等）

### 安装步骤

1. **克隆或下载项目到本地**

2. **创建并激活虚拟环境（推荐）**
```bash
cd brand_social_agent
python -m venv venv

# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate
```

3. **安装依赖**
```bash
pip install -r requirements.txt
```

4. **配置环境变量**
```bash
# 复制示例配置
copy .env.example .env

# 编辑.env文件，填入你的API配置
```

## ⚙️ .env 配置说明

```env
# LLM API配置（必填）
LLM_API_KEY=your_api_key_here

# API地址（使用OpenAI官方API）
LLM_BASE_URL=https://api.openai.com/v1

# 或使用其他兼容API（如硅基流动、DeepSeek等）
# LLM_BASE_URL=https://api.siliconflow.cn/v1

# 模型名称
LLM_MODEL=gpt-4o-mini
```

### 支持的模型服务商

| 服务商 | BASE_URL 示例 | 说明 |
|--------|--------------|------|
| OpenAI | `https://api.openai.com/v1` | 官方API |
| 硅基流动 | `https://api.siliconflow.cn/v1` | 需注册获取API Key |
| DeepSeek | `https://api.deepseek.com/v1` | DeepSeek官方API |
| 本地模型 | `http://localhost:11434/v1` | Ollama本地部署 |

## 📝 配置文件说明

### brand_facts.json - 品牌事实库

定义品牌/产品的基础信息：
- 产品名称、描述
- 活性成分
- 适用场景
- 禁忌人群
- 品牌定位

### content_rules.json - 平台规则

各平台的内容规范：
- 平台特性描述
- 内容风格要求
- 目标人群画像
- 禁用内容规定

### forbidden_words.json - 禁用词库

- `forbidden_words`: 绝对化用语、医疗效果承诺等禁用词
- `medical_risk_words`: 需要复核的医学风险词
- `violation_categories`: 违规分类及处理建议

### image_prompt_template.json - 图片提示词模板

包含各类型图片的提示词模板：
- 小红书封面、插图
- 抖音视频封面、画面
- 视频号海报
- 通用社交海报

### history_samples.json - 历史样例

优质历史内容样例供参考：
- 选题标题
- 内容大纲
- 脚本示例
- 图片提示词

## ⚠️ 重要约束

1. **AI输出水印** - 所有AI生成内容强制附带「AI初稿，需业务+医学法规人工审核后方可对外使用」

2. **禁用词检测** - 命中禁用词/医学风险词会红色高亮警告

3. **禁止内容** - 严禁输出：
   - 疗效对比、治疗承诺
   - 绝对化用语（第一、最好等）
   - 未经证实的功效描述
   - 医疗效果保证

4. **任务日志** - 所有操作完整记录在`task_logs/`目录，方便复盘

5. **图片生成** - 系统仅输出提示词，不调用绘图API

## 🔧 常见问题

### Q: 启动报错 "LLM_API_KEY未配置"

A: 请检查`.env`文件中`LLM_API_KEY`是否正确填写，不要留空或使用默认值。

### Q: API调用超时

A: 检查网络连接，或在`main.py`中调整`timeout`参数。

### Q: 选题/脚本生成质量不佳

A: 可以在`config/`目录下的JSON文件中丰富品牌事实、历史样例等配置。

### Q: 想使用本地部署的模型

A: 安装Ollama后，配置`.env`：
```
LLM_API_KEY=ollama
LLM_BASE_URL=http://localhost:11434/v1
LLM_MODEL=qwen2.5:14b
```
